WordPress recovery & troubleshooting

Victoria Ballet

An Elementor update left the academy's existing WordPress website with incompatible Core/Pro versions and PHP fatal errors.

What I did
Diagnosed the incompatibility, restored a verified Duplicator backup, and validated functionality after recovery. Investigated server responsiveness across Plesk, nginx, Apache, and PHP, and assessed staging, caching, and safer plugin-update practices.
Outcome
Restored the website to a working baseline and checked functionality after recovery.

Legacy website modernization

Esteline

The business's AngularJS website needed a simpler foundation, improved mobile layouts, and clearer search metadata.

What I did
Migrated to static HTML, CSS, and JavaScript; improved responsive layouts and accessibility; added page-specific SEO metadata, canonical URLs, Open Graph, JSON-LD, robots.txt, and a sitemap. Implemented consent-gated Meta Pixel and deployed through GoDaddy/cPanel with a rollback backup preserved.
Outcome
Delivered a responsive static website that no longer depends on the AngularJS runtime, with technical SEO metadata and consent-gated tracking.
